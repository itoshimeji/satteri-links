# 💬 satteri-link-mention

`satteri-link-mention` converts an empty HTTP or HTTPS Markdown link into an
inline mention while Markdown is processed.

> **Experimental:** The API, generated HTML, CSS class names, and behavior may
> change incompatibly between releases.

## 👩‍🚀 Astro setup

Sätteri is the default Markdown and MDX pipeline in Astro 7. Configure the
plugin through `@astrojs/markdown-satteri` in `astro.config.mjs`:

```js
import { satteri } from "@astrojs/markdown-satteri";
import { defineConfig } from "astro/config";
import { satteriLinkMention } from "satteri-link-mention";

export default defineConfig({
  markdown: {
    processor: satteri({
      hastPlugins: [satteriLinkMention()],
    }),
  },
});
```

## 🎨 Styling this demo

The plugin emits class names but does not inject CSS. This page uses the
optional preset shipped with the package:

```ts
import "satteri-link-mention/preset.css";
```

The preset can be omitted and replaced with site-specific CSS.

## ⚙️ Change the part order

Use `mention.order` to control the order of the enabled parts.

### Config

```ts
satteriLinkMention({
  mention: {
    order: ["siteName", "title", "favicon"],
  },
});
```

### Output

<Fragment set:html={reorderedMention.html} />

---

## ⚙️ Hide the favicon

Set `mention.favicon` to `false`.

### Config

```ts
satteriLinkMention({
  mention: {
    favicon: false,
  },
});
```

### Output

<Fragment set:html={noFavicon.html} />

## ⚙️ Show only the title

Each mention part can be enabled independently.

### Config

```ts
satteriLinkMention({
  mention: {
    favicon: false,
    siteName: false,
    title: true,
  },
});
```

### Output

## 💾 Caching

Metadata is cached under `.cache/satteri-link-mention` by default. Favicons
remain remote by default. Configure both caches in the plugin definition:

```ts
satteriLinkMention({
  metadataCache: {
    directory: ".cache/link-mentions",
    maxAge: 30 * 24 * 60 * 60 * 1000,
  },
  imageCache: {
    maxImageBytes: 5 * 1024 * 1024,
    store: createFileSystemImageCacheStore({
      directory: "public/link-mentions",
      publicPath: "/link-mentions",
    }),
  },
});
```

Set `metadataCache: false` to disable metadata caching. Set `imageCache: true`
to use the default filesystem store, or provide a custom `ImageCacheStore` for
another backend.

## ⚠️ Limitations

Metadata and image requests run in the build environment. Requests to private
or local network addresses are not currently blocked. Use the plugin with
trusted Markdown.

Missing favicon and site-name values are omitted. If metadata cannot be
resolved, the empty link is left unchanged.
