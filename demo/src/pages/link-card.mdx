# 🌌 satteri-link-card

`satteri-link-card` converts a standalone HTTP or HTTPS URL into a
metadata-rich card while Markdown is processed.

> **Experimental:** The API, generated HTML, CSS class names, and behavior may
> change incompatibly between releases.

## 🎨 Styling this demo

The plugin emits class names but does not inject CSS. This page uses the
optional preset shipped with the package:

```ts
import "satteri-link-card/preset.css";
```

The preset can be omitted and replaced with site-specific CSS.

## 👨‍🚀 Astro setup

Configure the plugin through `@astrojs/markdown-satteri` in
`astro.config.mjs`:

```js
import { satteri } from "@astrojs/markdown-satteri";
import { defineConfig } from "astro/config";
import { satteriLinkCard } from "satteri-link-card";

export default defineConfig({
  markdown: {
    processor: satteri({
      hastPlugins: [satteriLinkCard()],
    }),
  },
});
```

## ✅ Default card

A bare URL must be the only content in a root-level paragraph. The default card
shows the resolved title, description, favicon, thumbnail, and hostname when
that metadata is available.

## ❌ Links that are not converted

The plugin intentionally leaves the following input unchanged:

- links with authored labels or surrounding text
- URLs in lists, blockquotes, and other nested content
- paragraphs containing more than one link or other content
- non-HTTP(S) URLs
- URLs matched by `ignoreExtensions`

### Example

```markdown
Read the [Astro documentation](https://astro.build/).

- https://astro.build/

https://github.com/ItoShimeji/satteri-links https://astro.build/
```

## 💾 Caching

Metadata is cached under `.cache/satteri-link-card` by default. Images remain
remote by default. Configure both caches in the plugin definition:

```ts
satteriLinkCard({
  metadataCache: {
    directory: ".cache/link-cards",
    maxAge: 30 * 24 * 60 * 60 * 1000,
  },
  imageCache: {
    maxImageBytes: 5 * 1024 * 1024,
    store: createFileSystemImageCacheStore({
      directory: "public/link-cards",
      publicPath: "/link-cards",
    }),
  },
});
```

Set `metadataCache: false` to disable metadata caching. Set `imageCache: true`
to use the default filesystem store, or provide a custom `ImageCacheStore` for
another backend.

## ⚠️ Limitations

Metadata and image requests run in the build environment. Requests to private
or local network addresses are not currently blocked. Use the plugin with
trusted Markdown.

SVG images are not stored by the initial image cache. The package also does not
currently provide offline builds, cache pruning, or concurrency limits across
different URLs.
